# Employee Management Portal

A full-stack Internal Employee Management Portal built using the MERN stack as part of the Tryonix internship assignment.

## Features
- Authentication & Role-Based Access (Admin & Employee)
- Employee Directory
- Leave Management
- Task Management
- KPI & KRA Tracking
- Responsive Dashboard

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT Authentication
